🏨 Hostel Management System

The Hostel Management System is a full-stack application designed to simplify hostel administration, automate daily operations, and manage students, rooms, bookings, fees, and staff efficiently.
This project is built using Node.js, Express, and MongoDB, offering a scalable and secure backend architecture.

📌 Project Information

The Hostel Management System provides an easy way for hostel administrators to handle:

Student Registration & Management

Room Allocation and Availability Tracking

Fee Management and Payment Records

Admin Authentication using JWT

Database Management with MongoDB

Real-time data operations using REST APIs

This project is suitable for college mini-projects, major projects, demo systems, or learning backend development using Node.js & MongoDB.

⭐ Features

🔐 Secure Admin Login (JWT-based authentication)

🏠 Room Management (add, update, delete rooms)

👨‍🎓 Student Management (assign rooms, update details)

💰 Fee & Payment Tracking

📊 Dashboard with Key Statistics

📁 MongoDB Database Integration

⚡ REST API-based architecture

🛠 Easy to configure and run locally

🧰 Tech Stack
Technology	Description
Node.js	Runtime environment
Express.js	Backend framework
MongoDB	NoSQL database
Mongoose	MongoDB ORM
JWT	Authentication
Nodemon	Developer server


📥 Installation & Setup
1. Download the ZIP file

Extract it on your system.

2. Open Project

Open the hostelManagement folder in Visual Studio Code.

⚙️ Environment Setup

Create a .env file in the hostelManagement folder:

NODE_ENV = development
PORT = 4050
MONGODB_URI = mongodb://localhost/hostel
MONGOOSE_DEBUG = true
JWT_SECRET = your_jwt_secret_key


Replace your_jwt_secret_key with a strong secure key.

📦 Install Dependencies

Run:

npm install

🚀 Start the Project
Start the application
npm run start

Start the server in developer mode
npm run server# Hostel_Management_System
